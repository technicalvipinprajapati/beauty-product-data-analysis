# Week 2 – Data Identification and Sourcing Strategy

## Project Title
Beauty Product Review Analysis and Customer Satisfaction Insights

## Objective
The objective of this week is to identify suitable public data sources and prepare a structured data collection and exploratory data analysis (EDA) plan for the Beauty and Wellness domain.

## Primary Dataset
**Dataset:** Sephora Products and Skincare Reviews

**Source:** https://www.kaggle.com/datasets/nadyinky/sephora-products-and-skincare-reviews

The dataset contains product information, brand names, prices, ratings, categories and customer reviews.

## Additional Data Sources
1. Open Beauty Facts – https://world.openbeautyfacts.org/data
2. US FDA Cosmetics – https://www.fda.gov/cosmetics
3. Google Trends – https://trends.google.com/trends/
4. Reddit API – https://www.reddit.com/dev/api/

## Initial Dataset Information
- Product records: 8,494
- Unique brands: 304
- Customer reviews: Approximately 1,094,411
- Average product rating: Approximately 4.19/5
- Average customer review rating: Approximately 4.3/5
- Recommendation rate: Approximately 84%

## Data Quality Assessment
The dataset will be checked for missing values, duplicate records, inconsistent data types, invalid ratings and incorrect price values.

## Exploratory Data Analysis Plan
The following techniques will be used:
- Mean, median and standard deviation
- Frequency distribution
- Brand and category comparisons
- Rating and price analysis
- Correlation analysis
- Bar charts, histograms, box plots and scatter plots
- Customer review text exploration

## Data Cleaning Plan
Python Pandas will be used to handle missing values, duplicate records, inconsistent text and data types. Large review files will be processed in chunks.

## Tools Used
- Python
- Pandas
- Matplotlib
- GitHub

## Expected Outcome
This planning will help identify customer satisfaction patterns, understand product performance and discover common positive and negative customer experiences in the Beauty and Wellness industry.
